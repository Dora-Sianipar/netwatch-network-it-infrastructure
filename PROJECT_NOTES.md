# NetWatch project notes

## Portfolio positioning
Target internship roles: IT Support, Network Technician, NOC Technician, Junior Network Engineer, Infrastructure Support, System Administrator trainee.

## Suggested demo flow
1. Overview: explain simulated network-health indicators.
2. Topology: explain core router, distribution switches, access switches and access points.
3. Device Inventory: search a device, filter status, add a device, inspect it.
4. IP Address Manager: explain VLANs, subnet utilization, static vs DHCP assignments; add a demo subnet and export CSV.
5. Service Tickets: create an incident, start work, resolve it; explain the ticket lifecycle.
6. Maintenance: review schedule and tick preventive-check items.
7. Reports: export operational summary.

## Concepts to prepare
- What is a router vs switch vs access point?
- What is VLAN and why separate student, administration, and infrastructure networks?
- What are private IPv4 addresses and CIDR/subnet masks?
- What is DHCP vs static IP?
- What steps would you take if a device cannot be reached?
- Why is preventive maintenance useful?
- Difference between monitoring simulation and real monitoring?
